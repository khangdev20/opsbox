SECURITY

A panel with root access should be hard to reach.

So it is locked down from the first minute, without you having to know how.

✓
Locked until you claim itBefore setup only the claim page answers, and it needs a one-time token from your server boot log.
✓
Two-factor and lockoutTOTP on every account, sign-in lockout after repeated failures, every action in an audit log.
✓
Signed releasesThe installer verifies checksums and signatures before anything runs.
✓
Memory-safe by designThe agent is written in Rust: no garbage-collected runtime to install, and a whole class of memory bugs ruled out by the compiler.
✓
Safe modeA separate watchdog restarts opsbox, rolls back a bad update and can open SSH for an hour if you need it.

No telemetryopsbox sends nothing home. Your servers talk only to you.

Open sourceRead every line. Report issues privately through SECURITY.md.
FAQ

Questions, answered.

Is it really free?

Yes. opsbox is open source under Apache-2.0. There is no paid tier and no account to create. You pay only for your own servers.

Is it ready for production?

Not yet. opsbox is in alpha. Use it for side projects and staging first, and keep backups somewhere off the server.

Which servers does it run on?

Any recent Linux with systemd: Ubuntu, Debian, Amazon Linux, Fedora and similar, on x86_64 or arm64. Any cloud or a box under your desk.

How is it different from Coolify or Dokploy?

opsbox manages the server itself as well as your apps (updates, firewall, users, disk, files) and is locked behind a one-time setup token and 2FA from the first minute.

Can I manage more than one server?

Each install manages the server it runs on. opsbox Desktop, planned for later, will manage many servers and spread apps across them.

What happens if opsbox itself breaks?

Your apps keep running. A watchdog restarts or rolls back opsbox, and the command line on the server can repair it.
