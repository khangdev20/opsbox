Where to find these keys

  1. In the Cloudflare dashboard open R2 Object Storage and create a bucket.
  2. Go to Manage R2 API Tokens › Create API token.
  3. Choose Object Read & Write and limit it to that one bucket.
  4. Copy the Access Key ID and Secret here. Cloudflare shows the secret only once.
