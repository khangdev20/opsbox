      How it works
      
From a fresh instance to a live app in minutes.

      
No Kubernetes, no YAML to learn, no separate control server to pay for.

    

    

      
1
Install the agent
Run one command, or paste it into your cloud provider's user data when you launch the instance.
curl -fsSL https://github.com/khangdev20/opsbox/releases/latest/download/install.sh | sh

      
2
Open your panel
The install prints a setup link and a one-time token. Open it in your browser, create your account and turn on 2FA.
https://203.0.113.10:8443  token 7QK2-9XMD-4TFA

      
3
Ship your first app
Connect GitHub, pick a repo, add a domain with HTTPS. Every push to main deploys by itself.

      Security
      
A panel with root access should be hard to reach.

      
Alpha: treat panel process compromise as host-root compromise. Restrict panel access with a VPN, SSH tunnel, or IP allowlist, and restrict Safe Mode separately.

    

    

      
✓
Locked until you claim itBefore setup only the claim page answers, and it needs a one-time token from your server's boot log.

      
✓
Restrict Safe ModeThe root watchdog normally follows the panel IP on port 8444. Fix 21 adds exact-address filtering before TLS with [watchdog] allow_ips; an empty/default list permits remote access to recovery authentication. Restart opsbox-watchdog after changes, include loopback for tunnels, and check exposure/fingerprint with opsbox status. It has a separate root-only TLS key.

      
✓
Two-factor and lockoutTOTP enrolment, sign-in lockout after repeated failures, and audit records help protect panel accounts. These controls do not contain a compromised panel process.

      
✓
No telemetryopsbox does not send telemetry. Configured deployments, updates, certificates and notifications contact their external services.

      
✓
Signed releasesThe installer verifies checksums and signatures before installing a downloaded binary. Security fixes target the latest alpha release only.

      
✓
Trusted deployers and sensitive tokensFix 19 makes elevated Compose Admin-only; this alpha does not sandbox hostile tenants. Grant Deployer access only to trusted people. Full API tokens mean everything except root-equivalent actions after fix 20; ordinary deployments remain available, so protect and revoke leaked tokens.

      
✓
Panel has root-equivalent accessThe panel runs as opsbox and can request every typed operation from the root helper, including root jobs and terminals. Fixes 26/27 give the proxy a separate UID/socket and allow only port-holder queries and proxy: secret operations. Proxy compromise still exposes routed traffic and certificates. Existing hosts must install the fixes and restart services.

      
✓
Open sourceRead every line. Report issues privately through SECURITY.md; threats and controls in the threat model.

    

  






  

    

      FAQ
      
Questions, answered.

    

    

      
Is it really free?
Yes. opsbox is open source under Apache-2.0. There is no paid tier and no account to create. You pay only for your own servers.

      
Is it ready for production?
Not yet. opsbox is in alpha. Use it for side projects and staging first, and keep backups somewhere off the server.

      
Which servers does it run on?
Alpha release targets: Ubuntu 22.04, Ubuntu 24.04 and Debian 12 on x86_64 or arm64 (systemd). Other recent Linux may work; they are not the release bar yet. Any cloud, or a box under your desk.

      
How is it different from Coolify or Dokploy?
opsbox manages the server itself as well as your apps (updates, firewall, users, disk, files) and is locked behind a one-time setup token and 2FA from the first minute.

      
Can I manage more than one server?
Each install manages the server it runs on. opsbox Desktop, planned for later, will manage many servers and spread apps across them.

      
What happens if opsbox itself breaks?
Your apps keep running. A watchdog restarts or rolls back opsbox, and the command line on the server can repair it.
